# Web UI 使用说明

基于 Streamlit 的图形化界面

## 快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动Web服务
streamlit run src/app.py

# 3. 打开浏览器
# 自动打开 http://localhost:8501
```

## 界面功能

### 📤 上传视频
- 支持 MP4, MOV, AVI 格式
- 点击 "Browse files" 选择视频

### ⚙️ 设置选项
- **最大手数量**: 1 或 2
- **检测置信度**: 0.3 ~ 1.0
- **显示手势**: 开启/关闭手势识别
- **显示关节角度**: 开启/关闭角度标注

### 🚀 RUN 按钮
- 上传视频后点击 RUN 开始处理
- 处理完成后自动显示结果
