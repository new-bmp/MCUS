# 手部解剖学参考

## 手部骨骼结构

### 手腕 (Wrist)
- 8块腕骨组成
- 连接前臂和手掌
- 关键点 0 (WRIST) 位于腕骨中心

### 手指 (Digits)

每根手指由3节指骨组成：
- **近节指骨** (Proximal Phalanx) - 靠近手掌
- **中节指骨** (Middle Phalanx) - 中间（食指到无名指有，小指无）
- **远节指骨** (Distal Phalanx) - 指尖

### 关节

| 关节 | 缩写 | 说明 |
|------|------|------|
| CMC | 腕掌关节 | 手腕和掌骨之间 |
| MCP | 掌指关节 | 掌骨和近节指骨之间 |
| PIP | 近端指间关节 | 近节和中节指骨之间 |
| DIP | 远端指间关节 | 中节和远节指骨之间 |
| IP | 指间关节 | 拇指只有一个 |

## 手指弯曲角度定义

### 自然伸展状态
- PIP关节: ~170-180°
- DIP关节: ~150-160°
- 弯曲时: < 90°

### 角度计算方法

```python
def calculate_finger_angle(p1, p2, p3):
    """
    计算关节角度
    p1, p2, p3: 三个连续关键点
    p2是关节中心
    """
    v1 = p1 - p2  # 向量1
    v2 = p3 - p2  # 向量2

    # 计算夹角
    cos_angle = (v1 · v2) / (|v1| × |v2|)
    angle = arccos(cos_angle)
    return degrees(angle)
```

## 拇指特殊性

拇指只有2个关节（CMC, MCP, IP），比其他手指少一个DIP关节。
拇指的活动范围更大，可以对掌。

### 拇指角度计算
需要参考食指MCP的位置来计算拇指的弯曲角度。

## 可视化建议

1. **关键点大小**: 根据深度(z)调整，远的点小一些
2. **骨骼粗细**: 关节处细，连线处粗
3. **颜色编码**:
   - 拇指: 黄色
   - 食指: 红色
   - 中指: 绿色
   - 无名指: 蓝色
   - 小指: 紫色
   - 手腕: 白色
