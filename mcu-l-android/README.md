# MCUS Android

MCUS 是一个离线 MCU 选型应用，采用现代浅色、紧凑且信息密集的 Android 界面，并使用独立的 MCUS 芯片标识。

当前 APK 随包包含目录快照中的全部数据：18 个厂商、332 个系列、1,200 条产品线、13,791 个器件变体，以及 20,853 个已由官方来源核验的完整订货号。MM32 系列已归并为 F / G / H / L / P / SPIN / W 七个大类，因此系列数减少不代表型号减少。

本次存储资料补充包括 596 份官方来源、6,784 条 Flash/RAM 原文证据和 367 张架构图；其中 8,715 个器件关联 Flash 章节、7,713 个器件关联 RAM 章节。资料保留手册页码、适用型号和测试条件，详情页按存储地址、Flash、RAM、Cache 和架构图分组展开。

## 功能

- 厂商 → 系列大类 → 产品线 → 器件变体 → 完整订货号的逐层目录
- 型号、系列、产品线、完整订货号和外设名称搜索
- 厂商、核心、外设种类与外设最少数量筛选
- 核心、最高频率、Flash、RAM、TIM、ADC、连接外设等详情
- 典型功耗与运行 / 睡眠电流：仅展示带明确单位的官方来源测量值，同时保留频率、电压、温度等测试条件；条件不完整时明确提示，绝不把模式数量或无单位参数当作功耗
- 来源外设清单：I²S、看门狗、RTC、LIN、SDIO、比较器、触摸、显示、摄像头、外部总线、安全单元等
- 外部存储总线按来源逐器件展开：FMC/FSMC、OCTOSPI/OSPI、QSPI、XSPI、FlexSPI、HyperBus、EMIF/EBI 等，并提供用途说明
- ADC 转换器单元、ADC 通道与 CMSIS 原始参数分栏显示；不把 ADC 引脚数量作为选型指标
- 厂商卡片使用随包离线 Logo，加载失败时回退到厂商缩写
- 沁恒（WCH）CH32 系列按官方型号、封装变体和外设资源收录；搜索支持“沁恒”“WCH”“QingKe”别名
- 先楫半导体（HPMicro）HPM5 / HPM6 系列按官网选型型号与完整购买型号分开收录，并保留 PLA、PLB、SEI、MMC、PSEC、FFA、MTG 等原厂 IP 名称
- MCUS 选型指数及数据覆盖率
- 国民技术（Nationz / NSING / N32）：官方选型器六个类别、47 条产品线、273 个精确型号，243 个型号关联已验证的直接数据手册；内核、双核频率、ADC 单元 / 通道 / 原生分辨率分别记录
- 灵动微电子（MindMotion / MM32）：286 个变体，比上一快照新增 129 个；162 个精确型号由当前官网表格确认，其余历史 Pack 型号保留。未明确含义的 ADC 数量不推断为转换器或通道数
- TI C2000 DSP：收录 C28x 实时控制器及其 FPU、TMU、VCU、CLA、ADC、PWM 和通信资源；明确标记为 DSP 实时控制器，不与 Arm Cortex-M 混淆
- 雅特力（Artery / ArteryTek）AT32 系列：按 AT32F、AT32A、AT32L、AT32M、AT32WB 系列大类进入，收录 26 条产品线、222 个官方型号变体，并支持“雅特力 / Artery / AT32”搜索
- 厂商加速器和特性；待核验候选与已支持能力明确分开
- 详情页按核心存储、外设、封装、手册、来源清单、特性、评分和订货号分组折叠；来源外设组内再按类别展开
- 最多四款器件离线对比；功耗只有在单位与测量口径可比时才突出更低值
- STM32F103 后缀变体与官方完整订货号展示
- 器件详情中的封装示意图：按来源封装名称和引脚数绘制 QFP、QFN、BGA、LGA、SOP、DIP 等外形；精确焊盘和引脚定义以手册为准
- 器件详情中的官方手册与资料：在线 HTTPS 文档可直接打开，CMSIS Pack 内相对路径保留并可打开来源 Pack
- 1.5pre2 预览包显示立创查询入口；未配置授权时仅提示尚未接入，不显示虚假价格。云汉芯城和立创商城试接代码由服务端开关控制，器件详情仍只使用官方完整订货号
- “数据”页提供立创接口地址输入框，用户可填写自己的 HTTPS Worker / 授权网关；地址仅保存在本机，API Key 不进入 App。
- 全志目录只收录 8 个独立 XR 无线 MCU；A / T / MR / V / R SoC 和 XR 连接芯片不混入 MCU 目录
- 瑞萨目录收录 RA、RX、RL78、RH850、Synergy 和瑞萨 RISC-V：5,461 个基础型号、15,607 个官网完整订货号；RZ MPU/SoC 不混入 MCU 目录
- 独立的 `MicroPy MCU` 条目收录 RP2040、RP2350A/B、RP2354A/B、Kendryte K210、K230/K230D 和 K510；K230/K230D 标记官方 CanMV MicroPython，RP2354 标记堆叠 Flash 兼容性状态，K510 未核验的字段保持空白

## 重新打包

在 PowerShell 中运行：

```powershell
.\build.ps1
```

默认生成不含助手模型的轻量版 `dist\MCUS-1.5-debug.apk`。

构建脚本使用工作区 `.tools\android-build` 内的本地 JDK 与 Android SDK，不依赖系统全局环境。默认构建显示立创查询入口，未配置授权时只提示尚未接入；云汉接口使用 `-EnableQuotes -QuoteApiEndpoint <HTTPS Worker 地址>`，立创商城授权网关使用 `-EnableLCSCQuotes -LCSCQuoteApiEndpoint <HTTPS Worker 地址>` 构建试用包。两种入口都只按完整订货号查询。

## 1.5 应用结构

- 助手页面、自然语言推荐功能、本地模型和推理运行库已经从应用中移除。
- APK 版本为 1.5（versionCode 32）；界面版本与目录快照版本分开，网页脚本缓存按内容更新。
