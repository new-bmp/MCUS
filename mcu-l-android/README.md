# MCUS Android

MCUS 是一个离线 MCU 选型应用，采用现代浅色、紧凑且信息密集的 Android 界面，并使用独立的 MCUS 芯片标识。

当前 APK 随包包含目录快照中的全部数据：9 个厂商、197 个系列、696 条产品线、6,728 个器件变体，以及 303 个已由官方来源核验的完整订货号。

## 功能

- 厂商 → 系列大类 → 产品线 → 器件变体 → 完整订货号的逐层目录
- 型号、系列、产品线和完整订货号搜索
- 厂商与核心筛选
- 核心、最高频率、Flash、RAM、TIM、ADC、连接外设等详情
- 来源外设清单：I²S、看门狗、RTC、LIN、SDIO、比较器、触摸、显示、摄像头、外部总线、安全单元等
- ADC 转换器单元、ADC 通道、ADC 外部输入引脚与 CMSIS 原始参数分栏显示
- 厂商卡片使用随包离线 Logo，加载失败时回退到厂商缩写
- MCUS 选型指数及数据覆盖率
- 厂商加速器和特性；待核验候选与已支持能力明确分开
- 最多四款器件离线对比
- STM32F103 后缀变体与官方完整订货号展示

## 重新打包

在 PowerShell 中运行：

```powershell
.\build.ps1
```

生成文件位于 `dist\MCUS-0.6.0-debug.apk`。构建脚本使用工作区 `.tools\android-build` 内的本地 JDK 与 Android SDK，不依赖系统全局环境。

## 数据说明

目录覆盖表示当前已成功索引的数据来源，不代表所有厂商完整在售目录都已完成导入。订货号不会通过型号后缀的任意组合生成；没有官方记录时保持缺失。
